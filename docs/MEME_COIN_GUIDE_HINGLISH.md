## Common Mistakes (Galtiyan)

### ❌ Galat
1. **FOMO**: "Sab log kharid rahe hain, main bhi kharidta hun"
   - Result: Top pe entry, loss hota hai

2. **No Stop Loss**: "Thoda aur wait karta hun, wapas upar jayega"
   - Result: -80% loss

3. **Over-leverage**: "Sab paisa ek coin mein laga deta hun"
   - Result: Ek coin fail = portfolio khatam

4. **Ignoring Warnings**: "Risk warning hai but main lucky hun"
   - Result: Rug pull, scam

### ✅ Sahi
1. **Wait for Signal**: Dashboard pe BUY signal aane do
2. **Check Confidence**: 70%+ confidence wale signals lo
3. **Verify Risk**: "EXTREME DANGER" wale coins skip karo
4. **Small Position**: 1-2% se zyada mat lagao
5. **Set Stop Loss**: Entry ke baad turant lagao
